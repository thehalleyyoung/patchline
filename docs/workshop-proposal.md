# Conference workshop with reproducible demos

Patchline submits a conference workshop with accepted talks and **reproducible demo**s.

## How it works

The worker checks each accepted talk carries a demo marked reproducible.

## What the gate proves

- Every talk has a reproducible demo.
- A non-reproducible demo is rejected.

## Why it matters

Reproducible demos turn a workshop from slideware into something attendees can run themselves.

## Reproduce

```
make workshop-proposal-gate
```
