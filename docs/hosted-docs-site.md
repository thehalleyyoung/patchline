# Hosted documentation site

Patchline's hosted documentation site is generated by `scripts/build-docs-site.sh` and published by `.github/workflows/docs.yml` to GitHub Pages. The site is intentionally static: it needs only `bash`, `go`, `git`, and `jq`, and it embeds a regenerated public-repo analysis summary so tutorial examples stay tied to real code for maintainers, researchers, security reviewers, and contributors.

```bash
bash scripts/build-docs-site.sh \
  examples/docs-site-gate.json \
  results/generated/docs-site-gate
```

The generated site contains:

- `index.html`: landing page with a public `lobsters/lobsters` output snapshot.
- `tutorials/maintainers.html`: maintainer workflow for first-run analysis, triage, PR comments, and reviewer walkthroughs.
- `tutorials/researchers.html`: research workflow for claims-to-evidence maps, paper figures, limitations, and reproducible artifacts.
- `tutorials/security-reviewers.html`: security workflow for threat models, generated-code quarantine, release checksums, and offline validation.
- `tutorials/contributors.html`: contributor workflow for local checks, golden fixtures, fuzzing, plugins, and issue templates.
- `artifacts/public-demo.json`: the real public-repo summary embedded into the site.
- `sitemap.xml`, `.nojekyll`, and `site-manifest.json`: hosting metadata for GitHub Pages.

Run `make docs-site-gate` to regenerate the site from pinned public code and verify every role tutorial, hosting file, artifact link, and public-output threshold.
