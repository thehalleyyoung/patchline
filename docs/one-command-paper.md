# One-command reproduction of the entire paper

Patchline provides a **one command** that reproduces the entire paper in a clean container.

## How it works

The worker checks each paper artifact is regenerated by the single reproduction command.

## What the gate proves

- Every paper artifact is regenerated.
- A missing artifact is rejected.

## Why it matters

One command that rebuilds the whole paper is the gold standard for artifact reproducibility.

## Reproduce

```
make one-command-paper-gate
```
