# Certified integration-partner program

Patchline runs an integration-partner program with **certified**, reproducible joint deployments.

## How it works

The worker checks each partner is certified and ships a reproducible joint deployment.

## What the gate proves

- Every partner is certified and reproducible.
- An uncertified partner is rejected.

## Why it matters

Certified, reproducible partnerships are trustworthy integrations rather than logo announcements.

## Reproduce

```
make integration-partner-program-gate
```
