# ACM Results-Reproduced badge package

Patchline assembles an ACM Results-**Reproduced** badge package with an independent reviewer's sign-off.

## How it works

The worker checks each badge criterion is satisfied and carries an independent reviewer sign-off.

## What the gate proves

- Every badge criterion is met and signed off.
- An unmet criterion is rejected.

## Why it matters

The Results-Reproduced badge with independent sign-off is the strongest artifact-quality signal available.

## Reproduce

```
make acm-reproduced-badge-gate
```
