# Grand-unified evidence index

Patchline assembles a grand-unified evidence index proving **novelty**, rigor, adoption, and reproducibility in one place.

## How it works

The worker checks each of the four pillars resolves to a backing gate.

## What the gate proves

- Every pillar is gate-backed.
- An unbacked pillar is rejected.

## Why it matters

One index where novelty, rigor, adoption, and reproducibility each resolve to a gate is the capstone of the evidence story.

## Reproduce

```
make grand-unified-evidence-index-gate
```
