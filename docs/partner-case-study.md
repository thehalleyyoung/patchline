# Partner-adoption case study

Patchline runs a partner-adoption case-study program where each result bundle is **signed** and reproducible.

## How it works

The worker checks each case study carries a signature and a reproduce command and that both resolve.

## What the gate proves

- Every case study is signed and reproducible.
- An unsigned bundle is rejected.

## Why it matters

Signed, reproducible case studies are verifiable evidence of impact, not marketing claims.

## Reproduce

```
make partner-case-study-gate
```
