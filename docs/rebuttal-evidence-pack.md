# Rebuttal evidence pack

Patchline assembles a rebuttal evidence pack anticipating likely reviewer questions, each paired with a **reproducible answer** command.

## How it works

The worker checks every anticipated question has a backing command and an expected outcome that resolves.

## What the gate proves

- Every question has a reproducible answer.
- A question with no backing command is rejected.

## Why it matters

A rebuttal that answers each question with a runnable command is far more convincing than prose assurances.

## Reproduce

```
make rebuttal-evidence-pack-gate
```
