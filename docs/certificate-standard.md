# Standards proposal for the gate-certificate format

Patchline codifies the gate-certificate format as a standard for **interoperability**.

## How it works

The worker checks each certificate format field is fully specified and interoperability-tested.

## What the gate proves

- Every format field is specified and interop-tested.
- An underspecified field is rejected.

## Why it matters

A standardized certificate format lets an ecosystem of tools exchange verifiable verdicts.

## Reproduce

```
make certificate-standard-gate
```
