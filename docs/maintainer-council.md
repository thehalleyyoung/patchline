# Maintainer-council governance model

Patchline adopts a maintainer-council model with documented **decision record**s and term limits.

## How it works

The worker checks each governance element (council, decision records, term limits) is documented.

## What the gate proves

- Every governance element is documented.
- An undocumented element is rejected.

## Why it matters

Documented governance with term limits keeps a growing project accountable and avoids capture.

## Reproduce

```
make maintainer-council-gate
```
