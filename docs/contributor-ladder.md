# Contributor-ladder program with mentorship

Patchline defines a contributor-**ladder** with measurable progression and mentorship pairing.

## How it works

The worker checks each ladder rung has defined progression criteria and an assigned mentor.

## What the gate proves

- Every rung has criteria and a mentor.
- An undefined rung is rejected.

## Why it matters

A clear ladder with mentorship is how a project converts first-time contributors into maintainers.

## Reproduce

```
make contributor-ladder-gate
```
