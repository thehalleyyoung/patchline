# Examples gallery

Patchline renders a public **examples gallery** straight from the repository's own
example specifications and reproducibility reports. The gallery can never advertise
a capability that is not backed by a real example spec **and** a gate, because it is
generated by scanning `examples/*.json` and cross-referencing each entry against its
gate script (`scripts/<name>-gate.sh`) and capability doc (`docs/<capability>.md`).

## What it produces

`scripts/examples-gallery.sh` writes, under `results/generated/examples-gallery/`:

- `gallery.md` — a sorted Markdown table of every gate-backed capability with its
  pinned real-repo proof (where the spec declares one);
- `index.html` — a minimal, analytics-free static HTML index (no external assets);
- `examples-gallery.json` — the machine-readable gallery index with per-entry
  backing flags.

## How it stays honest

The gate (`scripts/examples-gallery-gate.sh`) asserts that the gallery is complete
(at least the configured minimum number of entries), **sorted**, and free of
**orphan** entries: every advertised capability must carry both a gate script and a
capability doc. If a future example spec is added without its gate or doc, the
gallery gate fails loudly — keeping the public, star-facing gallery in lockstep with
what the repository can actually prove.

## Reproduce

```
make examples-gallery-gate
```
