# 2.0 vision dossier

Patchline assembles a 2.0 vision dossier proving sustained **novelty**, rigor, adoption, and reproducibility, each pillar backed by a resolving gate.

## How it works

The worker checks every pillar has a backing gate and that all four pillars are covered.

## What the gate proves

- All four pillars are gate-backed.
- A dossier missing the reproducibility pillar is rejected.

## Why it matters

A vision where every pillar is gate-backed is a credible roadmap to a best-paper, widely-adopted tool.

## Reproduce

```
make vision-dossier-gate
```
