# Sustainability endowment plan

Patchline publishes a sustainability **endowment** plan ensuring multi-year maintenance with a budget.

## How it works

The worker checks each planned year has committed funding in the budget.

## What the gate proves

- Every plan year is funded.
- An unfunded year is rejected.

## Why it matters

A funded endowment plan is what keeps a widely-used project maintained for years, not abandoned.

## Reproduce

```
make sustainability-endowment-gate
```
