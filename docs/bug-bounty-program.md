# Funded bug-bounty program

Patchline runs a funded bug-**bounty** program with a published payout history and triage SLAs.

## How it works

The worker checks each accepted report was paid and triaged within the published SLA.

## What the gate proves

- Every report is paid and within SLA.
- An SLA-breaching report is rejected.

## Why it matters

A funded bounty with SLAs turns the security community into an active, rewarded part of the defense.

## Reproduce

```
make bug-bounty-program-gate
```
